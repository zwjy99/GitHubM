# 应用库布局与文件选择整理（1.0.20261031.6）

- 列表页只展示简短摘要、来源状态和一个主来源地址，其余地址以数量提示；来源完整内容仍保存在记录及详情中。初始显示 12 项，可继续加载。
- 扫描、导入、备份、添加和清空操作集中到独立的“扫描与管理”页。列表标题旁的“扫描 / 更新”会进入该页并发起扫描；“管理”只打开管理页。
- 应用详情分为“概览 / 匹配溯源 / 仓库关联 / 更多工具”，只渲染当前分区。默认概览不铺开签名、安装细节和完整溯源证据。
- 本机指纹、目录构建对照、项目资料及 README 按需展开；中文与英文简介单独切换。原有候选搜索、关联管理、APK 比较与 Fork 溯源功能均保留。
- 相同来源地址的尾部斜线、.git 和 GitHub 仓库大小写别名去重；不同仓库及不同分支地址不合并。
- 包名、网址、签名等技术字段不进入自动翻译；应用和贡献者名称保留原文，避免界面产生变形的地址或重复文字。
- APK / JSON 输入通过 Android ACTION_OPEN_DOCUMENT 和相应 MIME 交给文件管理器，不再一律加入相机选项。只有图片输入才允许拍照；选择取消时清理上次相机返回状态。
- 牡丹君条目仍为唯一一条，只保留作者主页链接，移除额外“查看参考项目”链接。
- ChatGPT 协助头像原样使用用户提供的 PNG，未裁切、重绘或使用外部图床。旧机器人 SVG 已被替换。

验证：159 项前端测试、TypeScript 检查，以及 4 项在实际编译后的 Kotlin FileChooserPolicy 上运行的 JUnit 文件选择规则测试通过。Android Release 与资源/签名校验随最终交付验证。没有宣称完成用户真机的视觉验收。

当前交付构建参数：VERSION_NAME=1.0.20261031.6，VERSION_CODE=20261036。签名复用此前已保存的备份，KEYSTORE_PATH / STORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD 由构建环境提供，不写入源码。
