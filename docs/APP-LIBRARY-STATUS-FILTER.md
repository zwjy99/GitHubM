# 应用库：独立列表筛选（2026-10-31）

## 页面行为

- “我的应用”左栏保留单独的文字搜索，新增一个与搜索框平级的「筛选」控制。
- 筛选条默认展开，可直接切换：全部 / 已确认来源 / 关联项目 / 待确认 / 未匹配。
- 每个选项标注**当前可见应用范围内的数量**（默认不含系统应用；打开“显示系统应用”后会随之更新）。
- 筛选真正过滤下方的应用列表；与名称、包名、版本、关联仓库文字搜索可以叠加使用。
- 状态是**应用列表的主状态**，优先级为：已确认来源 > 关联项目 > 待确认 > 未匹配。这样应用不会同时重复计入几个分类。
- 在某个应用的详情中，“已保存的仓库关联”允许分别查看来源仓库、相关仓库、待确认候选，因此一个应用**可以同时保存多种仓库关系**。
- 选中的应用若不再符合筛选条件，右侧旧详情自动隐藏，避免看到与当前筛选不相关的内容。

## “待确认”保存和资料兼容

- 搜索候选仓库后可点击「存为待确认」；手动输入仓库地址也可保存为待确认。
- 从已保存仓库关系的下拉选单可调整分类，无需删除再重新添加。
- `RepoLink.relation` 新增 `pending`，原有 `source` / `related` 值维持不变。
- 存储 Key **未迁移**（仍使用 `githubm_app_library_v1_<login>`），旧版 JSON 可以直接读取；导入、导出也保留新状态。
- “自行签名”仍是单独的 APK 签名属性，不影响来源确认状态。

## 性能与权限

- 本次列表筛选仅作用于已经保存在本地的应用记录，**不会触发额外 GitHub API、F-Droid 或 Fork 请求**，不会额外消耗搜索额度。
- 应用扫描、深度调查、APK 比对、Fork 安装包检查、OAuth/PAT 登录和双代理未被本次逻辑替换。

## Android 底部导航的额外改动

- 为适应系统字号缩放，将 BottomNavigationView 的高度从 62dp 调整到 80dp，图标 22dp、标签 11sp，补充上下间距。目标是减少原先截图中图标与中文标签挤压；需真机检查不同系统字体缩放下的效果。
